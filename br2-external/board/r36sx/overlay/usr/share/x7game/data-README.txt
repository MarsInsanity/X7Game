X7 Game - your data (X7DATA)
============================

Everything here is yours: X7 Game never deletes or formats this partition
once it exists, also when you flash a newer X7 Game image onto the card
(with balenaEtcher or Rufus in image mode; back up first anyway).

  roms\<system>\   your games, one folder per system (RecalBox names):
                   nes, snes, gb, gbc, gba, megadrive, mastersystem,
                   gamegear, pcengine, psx, neogeo, mame, fbneo, ...
  bios\            BIOS files some systems need (e.g. PlayStation)
  saves\           game saves and save states
  screenshots\     screenshots
  music\           music (mp3, flac, ogg, ...)
  videos\          videos (mp4, ...)
  photos\          pictures
  overlays\, shaders\, system\, userscripts\
                   for the frontend and emulators (coming later)

Missing folders are created again at every start. You can add your own.

On the console this drive is /share.

Updates: copy an x7game-...x7update file here and switch the console on.
